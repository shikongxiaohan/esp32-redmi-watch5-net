# 固件发布包

本项目编译产出的可直接烧录固件，文件名格式为 `watch5-net-<版本>-<用途>.bin`。

## 文件说明

| 文件 | 大小 | 用途 | 烧录方式 |
| --- | --- | --- | --- |
| `watch5-net-v1.1.2-ota.bin` | 1,837,280 B (1.75MB) | 应用 OTA 镜像 | Web「固件升级」页上传，或 esptool 写 `0x10000` |
| `watch5-net-v1.1.2-full-4mb.bin` | 4,194,304 B (4MB) | 整片合并镜像 | 仅 USB：`esptool write_flash 0x0`（首次烧录 / 救砖 / 安卓 OTG 线刷） |

> 两者**不能混用**：合并镜像包含 bootloader 与分区表，上传到 OTA 页会被拒绝；
> OTA 镜像用于已烧录过双 OTA 分区表的设备。

## 当前版本

- 版本号 **1.1.2**（定义于 `platformio.ini` 的 `XW_FW_VERSION`）
- 目标板：ESP32（经典蓝牙 + WiFi），**4MB Flash**
- 分区表：`partitions.csv`（双 OTA 槽 1,984KB + nvs + otadata + coredump）；
  16MB 板子到手后改用 `partitions-16mb.csv`（见 README「16MB 分区」说明）
- 资源占用：Flash 90.1%，RAM 26.5%

## 烧录命令

```bash
# 首次 / 换机 / 分区表变更后：整片烧录（会清除 WiFi 配置和蓝牙绑定）
esptool.py --chip esp32 --port /dev/ttyUSB0 --baud 921600 \
  write_flash -z 0x0 watch5-net-v1.1.2-full-4mb.bin

# 后续增量升级：只写应用分区
esptool.py --chip esp32 --port /dev/ttyUSB0 --baud 921600 \
  write_flash -z 0x10000 watch5-net-v1.1.2-ota.bin
```

更推荐的方式：整片烧录成功后，后续升级直接在 Web「固件升级」页上传 `-ota.bin`，
不用再插数据线。

## 校验

```bash
sha256sum -c SHA256SUMS.txt
```

## 自行编译

```bash
pio run                    # 产出 .pio/build/esp32dev/firmware.bin，等同 -ota.bin
pio run -t erase           # 分区表变更前必须先全擦
pio run -t upload          # 编译并 USB 烧录
```

生成整片合并镜像：

```bash
~/.platformio/packages/tool-esptoolpy/esptool.py --chip esp32 merge_bin \
  -o watch5-net-v1.1.2-full-4mb.bin \
  --flash_mode dio --flash_freq 40m --flash_size 4MB --fill-flash-size 4MB \
  0x1000  .pio/build/esp32dev/bootloader.bin \
  0x8000  .pio/build/esp32dev/partitions.bin \
  0xe000  ~/.platformio/packages/framework-arduinoespressif32/tools/partitions/boot_app0.bin \
  0x10000 .pio/build/esp32dev/firmware.bin
```

然后更新本目录的 `SHA256SUMS.txt`。
